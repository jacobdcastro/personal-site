# personal-site

Jacob D. Castro's personal site (v5) — a single-page, scroll-driven, 3D experience.

## Stack

- [TanStack Start](https://tanstack.com/start) (React 19 + Vite + SSR)
- [TanStack Router](https://tanstack.com/router) (file-based routing)
- [Tailwind CSS v4](https://tailwindcss.com)
- [react-spring](https://www.react-spring.dev) for animation

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run preview` — preview the production build
- `npm run lint` / `npm run format` / `npm run check` — lint, format, and check formatting
- `npm test` — run tests
